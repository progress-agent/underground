# Reproducible Balloon measurement

Use `scripts/measure-balloon.mjs <out-dir> <live-origin> <new-origin>` under the shared GPU lock. It runs fresh real-GPU headless Chromium contexts, DPR 1, 4x main-thread CPU throttle, Automatic, a 60-second settle, then a 2.5-second FPS window, live/new interleaved three times. Keep all CDP sessions attached until the browser closes: detaching can reset throttling. Primary gate runs do not enable the CPU profiler; the separate diagnostic files retain their profiles.

The standard view now explicitly resets the Balloon's third-person rig to yaw PI (south), pitch -0.12, zoom 1, at the existing Waterloo body placement. It previously inherited the prior camera heading, so running only Balloon and running the complete ten-view sequence were different pictures. Output records the actual measured camera position and quaternion. Let the Balloon drift as it does in play; record its final position, and use the same settle duration and view order for a comparison. The October 16 runs settled for 24 seconds; October 31 used 60 seconds. Neither pose nor elapsed flight may be silently substituted.

On production cfb8c44, the initial 60-second standalone case measured 48.83 fps; the complete-view warm-up followed by Balloon measured 19.15 fps. Their headings differ. The expensive south-facing case profiles at 19.71 fps / 50.54 ms CPU, with 19.63 seconds of a 74.71-second sample under station-name occlusion. Those rays repeatedly traversed detailed landmark triangles because only their loose bounding spheres were present. Computing exact geometry bounding boxes in the same live page's objects raises the same expensive case to 53.8 fps. `Mesh.raycast` uses those boxes solely for exact rejection before its existing triangle test; no rendered geometry, lighting, figure, label rule or Automatic rung changes.

The implemented fix computes those bounds when landmark pickables are registered. Structure height changes the containing anchor's scale; the geometry-local bounds remain valid. Final three-run figures and the frozen full-quality comparison belong in the sprint evidence, rather than being copied into this standing method document.
